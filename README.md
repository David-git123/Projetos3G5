# Projeto CARE-G5

Projeto desenvolvido para a disciplina de projetos 3 da CESAR School.

[Link da plataforma](https://projetos3g5.onrender.com/index.html)

## Em que consiste?
O projeto consiste em uma plataforma que permite o lançamento de pesquisa para seus usuários. Tem como o objetivo solucionar problemas de baixa taxa de resposta de formulários

## Como funciona?
Para acessar a plataforma é necessário se cadastrar, inserindo as informações solicitadas. Todas as contas criadas terão o nível de acesso apenas de "cliente". Nesse nível é possível buscar por empresas, receber e responder pesquisas. Para acessar uma conta com o nível de administrador é necessário que um super usuário dê esse tipo de permissão para alguma conta criada com o nível de cliente. 
É possível acessar a conta de super usuário por meio dos seguintes login e senha:

email: super@care.com

senha: super123

Além dessa funcionalidade a conta de super usuário também permite a criação e designação de pesquisas para deteminados usuários. A função de administrador não possui o privilégio de determinar o tipo de acesso das contas, possui apenas a capacidade de criar e enviar formulários de pesquisas para usuários.
